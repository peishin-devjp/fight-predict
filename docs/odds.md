# odds.md

# 難易度倍率・ポイント計算仕様

## 目的

Fight Predictにおける試合ごとの難易度倍率と、予想的中時の獲得ポイント計算ルールを定義する。

MVPでは、ユーザー全体の予想人数比率をもとに難易度倍率を決定し、
ユーザー自身が配分したポイントと組み合わせて獲得ポイントを計算する。

---

# Version 0.2（MVP採用仕様）

## 設計方針

難易度倍率と配分ポイントは、それぞれ異なる意味を持つものとして扱う。

- 難易度倍率：ユーザー全体から見た「その予想の難しさ」
- 配分ポイント：各ユーザー自身の「その予想への自信度」

配分ポイントを難易度倍率の計算にも使用すると、
ユーザーの自信度が「配分ポイント」と「難易度倍率」の両方に反映されるため、
MVPでは難易度倍率の算出に配分ポイント量を使用しない。

---

# ポイント配分ルール

MVPでは1大会につき最大100ptを配分する。

- 配分は1pt単位とする
- 1試合あたりの最大配分は50ptとする
- 1大会の合計配分は100pt以内とする
- 100pt未満でも保存可能とする
- 100ptを必ず使い切る必要はない
- 未使用ポイントは獲得ポイントには加算されない
- 全試合へのポイント配分は必須ではない

1試合50pt上限は、1試合への極端な一点集中によって
ランキングが大きく左右されすぎることを抑えながら、
「この試合に強く自信がある」というユーザーの意思も表現できるバランスとして採用する。

---

# 難易度倍率

## 基準

難易度倍率は、各選手を勝者として予想したユーザーの人数比率をもとに決定する。

ポイント配分量の合計・平均値は難易度倍率の計算には使用しない。

## Version 0.1 倍率テーブル

Version 0.2では、難易度倍率そのものはVersion 0.1の倍率テーブルを採用する。

| 予想人数比率 | 多数派倍率 | 少数派倍率 |
| --- | ---: | ---: |
| 50 : 50 | 2.00 | 2.00 |
| 60 : 40 | 1.80 | 2.50 |
| 70 : 30 | 1.50 | 3.00 |
| 80 : 20 | 1.30 | 3.50 |
| 90 : 10 | 1.10 | 4.00 |
| 95 : 5 | 1.05 | 4.50 |

単純な逆数オッズは採用しない。
Fight Predictのポイントは金銭を分配するパリミュチュエル方式ではないため、
理論上のフェアオッズに一致させる必要はない。

極端な少数派予想1回だけでランキングが決まりすぎることを防ぐため、
少数派側の倍率は意図的に圧縮する。

---

# 中間支持率の扱い

倍率テーブルの基準値の間にある支持率は、線形補間で算出する。

例：
70%側の倍率1.50と60%側の倍率1.80の間にある支持率については、
その位置に応じて倍率を補間する。

少数派側についても同様に、
30%側3.00と40%側2.50の間を線形補間する。

※5%未満／95%超の支持率をどのように扱うかは、実装前に別途確定する。

---

# 獲得ポイント計算

## HIT（的中）

試合結果が `finished` で、予想した選手が勝者だった場合：

**獲得ポイント = 配分ポイント × 難易度倍率**

例：
37pt × 1.30 = 48.1pt

## MISS（外れ）

試合結果が `finished` で、予想した選手が敗者だった場合：

**獲得ポイント = 0pt**

## REFUND（返却）

以下の試合結果では難易度倍率を使用せず、
配分ポイントを1倍で獲得ポイントとして扱う。

- `draw`
- `no_contest`
- `cancelled`

**獲得ポイント = 配分ポイント × 1.0**

## NOT_SETTLED（未確定）

`scheduled` の試合は結果未確定のため、ポイント計算を行わない。

---

# 端数処理

獲得ポイントは試合ごとに小数第1位までとする。

計算結果に小数第2位以下が発生した場合は、
**試合ごとに小数第2位を四捨五入して小数第1位にする。**

例：

33pt × 1.05 = 34.65pt  
→ 34.7pt

大会獲得ポイントは、各試合で端数処理した獲得ポイントを合計して算出する。

これにより、画面に表示される各試合の獲得ポイントの合計と
大会獲得ポイントが一致するようにする。

---

# 的中数ボーナス

Version 0.2では、的中試合数による追加ボーナスは設けない。

シミュレーションでは、

- 本命を中心に多数の試合を的中するユーザー
- 的中数は少ないが難しい予想を的中するユーザー

の双方がランキング上位を狙える結果となったため、
現時点では追加の的中数ボーナスは不要と判断する。

将来、実ユーザーデータを用いた検証で偏りが確認された場合は再検討する。

---

# ランキングとの関係

MVPのランキングは、直近3大会の獲得ポイント合計を基本とする。

大会単位・3大会単位のシミュレーションでは、
Version 0.2により特定の1戦略だけが常に有利になる状態は確認されなかった。

---

# オッズ確定タイミング

難易度倍率の元となる予想人数比率は、大会開始時点で確定させる想定とする。

確定後は、その大会のポイント計算に使用する倍率を変更しない。

---

# サービス初期の扱い

サービス開始直後など、ユーザー予想数が少なく、
予想人数比率だけでは倍率の信頼性が低い場合は、
外部情報を補助的に利用することを検討する。

補助情報の候補：

- ブックメーカーのオッズ
- SNS等の予想傾向
- 選手の戦績

具体的な参照元・補正方法・切替条件は別途設計する。

---

# Version履歴

難易度倍率は予想人数比率のみで決定し、
ユーザーの配分ポイント量は倍率計算に使用しない方針とした。

## Version 0.2

- 1試合最大50pt
- 1大会100pt以内
- 100pt未満でも保存可能
- ポイント配分は1pt単位
- 的中数ボーナスなし
- HIT：配分pt × 難易度倍率
- MISS：0pt
- draw / no_contest / cancelled：配分ptを1倍で返却
- 獲得ポイントは試合ごとに小数第1位へ四捨五入
- 大会獲得ポイントは端数処理後の試合別ポイントを合計
