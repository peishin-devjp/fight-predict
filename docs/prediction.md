# prediction.md

# 予想ルール

## 基本ルール

MVPでは、ユーザーは1大会につき最大100ptを各試合へ配分する。

- ポイント配分は1pt単位とする
- 1試合あたりの最大配分は50ptとする
- 1大会の合計配分は100pt以内とする
- 100pt未満でも保存可能とする
- 100ptを必ず使い切る必要はない
- 未使用ポイントは獲得ポイントには加算されない
- 全試合へのポイント配分は必須ではない
- 1大会合計が100ptを超える予想は保存不可とする

100pt未満でも保存できるため、ユーザーは自信のある試合だけ先に入力し、
後から残りの予想を調整できる。

---

# バリデーション方針

ポイント制約はFrontendとBackendの両方で確認する。

Frontendでは、1試合50pt超過・大会合計100pt超過を即時に防止し、
ユーザーへのフィードバックと不要なAPIリクエスト防止を担当する。

Backendでは、APIを直接呼ばれた場合でも
1試合50pt以内・同一大会100pt以内を保証し、
不正なポイント値がDBへ保存されないようデータ整合性を担保する。

---

# 難易度倍率

難易度倍率はユーザー全体の予想人数比率をもとに算出する。

配分ポイントは各ユーザー自身の「自信度」を表すものとし、
難易度倍率の計算には使用しない。

具体的な倍率表・補間方法は `odds.md` で管理する。

---

# ポイント計算

- HIT：配分ポイント × 難易度倍率
- MISS：0pt
- draw / no_contest / cancelled：配分ポイント × 1.0
- scheduled：結果未確定のためポイント計算しない

---

# 端数処理

獲得ポイントは試合ごとに小数第1位までとする。

計算結果に小数第2位以下が発生した場合は、
**試合ごとに小数第2位を四捨五入して小数第1位にする。**

例：

33pt × 1.05 = 34.65pt  
→ 34.7pt

大会獲得ポイントは、各試合で端数処理した獲得ポイントを合計する。

---

# 的中数ボーナス

Version 0.2では、的中試合数による追加ボーナスは設けない。

大会単位および直近3大会のシミュレーションで、
多数的中型と難関的中型の双方がランキング上位を狙える結果となったため、
現時点では追加ボーナスを設けない。

---

# ランキング

MVPのランキングは直近3大会の獲得ポイント合計を基本とする。

---
